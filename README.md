# 贪吃蛇 · 栗子游戏网

诺基亚风格的经典贪吃蛇网页小游戏，单个 HTML 文件，纯 Canvas 实现，无外部依赖。

在线试玩：https://jiaoyi.ximutan.com/snake/

## 玩法

- 方向键 / WASD 转向，Enter 确定，P / 空格 暂停，Esc 回菜单，M 静音
- 手机：滑动转向，轻点确定 / 暂停
- 吃到食物身体变长、加分，越吃越快；撞墙或撞到自己游戏结束
- 每吃 5 个食物会出现限时奖励小怪，越早吃到分越高
- 经典模式：四周是墙；穿墙模式：从一边出去从另一边回来
- 慢 / 中 / 快 三档难度，最高分按模式和难度分别记录

## 本地运行

直接用浏览器打开 `index.html` 即可。
